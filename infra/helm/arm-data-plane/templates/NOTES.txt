{{- if .Values.tls.controlPlaneMTLS.enabled }}

mTLS to the control plane is ENABLED. This chart never creates or holds key
material, so the secret must already exist or the pods will stay Pending:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.tls.controlPlaneMTLS.certSecretName }} \
    --from-file=tls.crt=client.crt --from-file=tls.key=client.key --from-file=ca.crt=ca.crt

  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.tls.controlPlaneMTLS.certSecretName }}
{{- end }}

{{- if and .Values.meterAgent.enabled (not .Values.persistence.enabled) }}

WARNING — meterAgent is enabled but persistence is off, so its event buffer is
an emptyDir. Unflushed metering events die with the pod. The buffer is on disk
precisely so a restart does not lose spend; set persistence.enabled=true.
{{- end }}

{{- if and .Values.meterAgent.enabled (not .Values.meterAgent.ingestTokenSecret.name) }}

WARNING — no meterAgent.ingestTokenSecret.name is set, so the agent will POST
to the control plane unauthenticated. The control plane REFUSES that under
NODE_ENV=production, and events will pile up in the buffer undelivered
(/health reports degraded, and says so in lastFlushError). Create the secret
and point at it:

  kubectl -n {{ .Release.Namespace }} create secret generic arm-ingest-token --from-literal=token=<value>
{{- end }}

{{- if or .Values.proxy.autoscaling.enabled (gt (int .Values.proxy.replicas) 1) }}

NOTE — the proxy is running {{ if .Values.proxy.autoscaling.enabled }}up to {{ .Values.proxy.autoscaling.maxReplicas }}{{ else }}{{ .Values.proxy.replicas }}{{ end }} replicas, and each holds
its own quota state on a local emptyDir. Daily caps are therefore enforced PER
REPLICA, so the effective cap is up to that many times the configured one.
Quota surviving a process restart is new; quota shared across replicas needs a
shared store and is not built yet. Run a single replica if the cap must be
exact.
{{- end }}

{{- if not .Values.ingress.enabled }}

No Ingress was created. Nothing outside the cluster can reach the data plane
yet — that is the default on purpose. Set ingress.enabled=true with hosts, or
expose it through your own gateway.
{{- end }}

Read before treating this as production: infra/README.md lists what this chart
still does not do. In particular there is NO meter-agent deployment — the
proxy writes metering events to its buffer and nothing drains them to the
control plane yet.
