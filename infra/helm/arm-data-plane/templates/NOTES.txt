{{- if and .Values.persistence.enabled (or .Values.proxy.autoscaling.enabled (gt (int .Values.proxy.replicas) 1)) }}

WARNING — the meter buffer PVC is ReadWriteOnce and you are running more than
one proxy replica. Replicas past the first will not schedule unless your
storage class supports multi-attach. Use a ReadWriteMany class, or set
persistence.enabled=false and accept that a restart drops buffered events.
{{- end }}
